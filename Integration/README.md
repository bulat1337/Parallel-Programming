# Integration

Численное интегрирование на общей памяти реализовано на C++ с использованием `pthread`.

Программа:

- считает интеграл функции `sin(1 / (x - 5))` на фиксированном интервале `[0; 4.999]`;
- использует адаптивную формулу Симпсона, поэтому шаг подбирается отдельно для каждого участка;
- распределяет подзадачи между потоками через общую динамическую очередь, что дает балансировку нагрузки;
- измеряет время последовательного и параллельного запуска, затем считает `speedup` и `efficiency`.

## Метод

Для каждого интервала вычисляется оценка Симпсона на текущем шаге и на двух половинах интервала. Если локальная ошибка меньше заданной `epsilon`, результат принимается. Иначе интервал делится еще раз.

Такой подход автоматически дает:

- мелкий шаг там, где функция меняется быстро;
- крупный шаг на гладких участках;
- естественную балансировку, потому что любой свободный поток берет следующую задачу из общей очереди.

Для функции `sin(1 / (x - 5))` это особенно важно: при приближении к `x = 5` осцилляции резко учащаются, поэтому адаптивный алгоритм вынужден дробить правую часть интервала намного сильнее, чем левую.

## Файлы

- `main.cpp` — исходный код решения.

## Компиляция

```bash
cd Integration
g++ -std=c++17 -O2 -Wall -Wextra -pedantic main.cpp -o integrate -pthread
```

## Запуск

```bash
./integrate <число_потоков> <допустимая_погрешность>
```

Пример:

```bash
./integrate 4 1e-8
```

## Что выводит программа

- значение интеграла при последовательном и параллельном расчете;
- время выполнения обоих вариантов;
- число обработанных подзадач и число вычислений функции;
- минимальный, максимальный и средний адаптивный шаг;
- распределение подзадач между потоками;
- `speedup = T1 / Tp`;
- `efficiency = speedup / p`.

## Примечание

Правая граница интервала выбрана равной `4.999`, а не `5`, потому что в точке `x = 5` выражение `1 / (x - 5)` не определено. На практике это делает задачу хорошим примером адаптивного интегрирования: чем ближе к правой границе, тем меньше шаг приходится выбирать.

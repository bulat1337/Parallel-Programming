# Лабораторная работа: уравнение переноса на MPI

Реализовано численное решение задачи

$$
\frac{\partial u(t,x)}{\partial t}
+ a\frac{\partial u(t,x)}{\partial x}
= f(t,x), \quad 0 \le t \le T,\quad 0 \le x \le X.
$$

$$
u(0,x)=\varphi(x), \quad 0 \le x \le X.
$$

$$
u(t,0)=\psi(t), \quad 0 \le t \le T.
$$

Используется явный левый уголок:

$$
u_m^{k+1}
= u_m^k
- c\left(u_m^k-u_{m-1}^k\right)
+ \tau f(t_k,x_m),
$$

$$
c=\frac{a\tau}{h}.
$$

В программе задан тестовый вариант с точным решением:

$$
u(t,x)=e^{-t}\left(1+\sin x\right).
$$

По нему вычисляются $\varphi(x)$, $\psi(t)$ и $f(t,x)$, поэтому программа выводит максимальную ошибку на последнем временном слое.

## Задание к допуску

Запуск измерения задержки:

```bash
mpirun -np 2 ./01_admission/latency_mpi 100000 1
```

Аргументы:

- `100000` - число ping-pong итераций.
- `1` - размер сообщения в байтах.

Программа выводит среднее время полного ping-pong круга и оценку задержки одной передачи в микросекундах.

## Задание к выполнению

Последовательный запуск:

```bash
./02_execution/transport_seq --M 400 --K 800 --output seq_profile.csv
```

Параллельный запуск:

```bash
mpirun -np 4 ./02_execution/transport_mpi --M 400 --K 800 --output mpi_profile.csv
```

Параметры:

- `--M` - число шагов по координате $x$.
- `--K` - число шагов по времени $t$.
- `--a` - скорость переноса, по умолчанию `1`.
- `--T` - конечное время, по умолчанию `1`.
- `--X` - правая граница по координате, по умолчанию `1`.
- `--output` - CSV-файл с последним временным слоем.
- `--csv` - компактный CSV-вывод одной строкой для автоматических измерений.

Для явной схемы проверяется условие устойчивости:

$$
c=\frac{a\tau}{h}\le 1.
$$

В MPI-версии число процессов должно быть не больше $M$, потому что распределяются узлы $1,\ldots,M$.
